# App-Inventor-Trivia
A space-themed mobile trivia application built with **MIT App Inventor**. The game tests users' knowledge through multiple-choice questions while tracking their score and providing visual and audio feedback.



## 🛠️ Components Used (MIT App Inventor)
* **User Interface:** `Label` (questions and score display), `Button` (answer choices), and `Slider` (progress indicator).
* **Media & Notifications:** `Sound` (audio feedback) and `Notifier` (on-screen pop-up alerts).
* **Graphic Assets:** Custom space-themed background images.

## 📱 How to Run the Project
1. Download the `.aia` project file from this repository.
2. Go to [MIT App Inventor](https://appinventor.mit.edu/).
3. Navigate to **Projects > Import project (.aia) from my computer...** and upload the downloaded file.
4. Use **MIT AI2 Companion** on your Android device or an emulator to test and run the app.
